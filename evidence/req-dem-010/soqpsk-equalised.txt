VERDICT

  Best any linear equaliser could do: 10.9130 %rms.

  The mismatch is NOT linear intersymbol interference and no equaliser removes
  it. That follows from what it is: the ternary alphabet's zeros make adjacent
  pulse tails add in phase, and WHICH symbols do that depends on the data. A
  linear filter applies the same response to every symbol by definition, so it
  cannot undo an error that changes with the symbol sequence.

  So the standard-derived c0 does not give a demodulator, and #440's two routes
  are still the only two. This measurement removes the third.
